## FSD CLI

**A CLI for starting and scaling frontend projects using Feature-Sliced Design.**

FSD CLI helps developers start projects with a clear architectural foundation instead of reorganizing the codebase after it becomes difficult to maintain.

```bash
npx create-fsd-architecture@latest my-app
```

### Supported Frameworks

`React + Vite` • `Next.js` • `Vue + Vite` • `Nuxt` • `SvelteKit`

</td>
</tr>
</table>

### ⚡ What FSD CLI Does

- 🚀 Scaffold new projects using Feature-Sliced Design
- 🧩 Generate Features, Entities, Widgets, and Pages
- ⚙️ Store architecture decisions inside `fsd.config.json`
- 🔍 Inspect existing project configuration
- 🛡️ Protect existing slices from accidental overwrites
- 👀 Preview changes using dry-run
- 📐 Keep architectural decisions consistent across the project
- 🧠 Reduce architecture decisions developers have to repeatedly make
- 📦 Support multiple frameworks through one workflow

### Example

```bash
npx create-fsd-architecture@latest my-app
```

Then continue working with the same architecture:

```bash
fsd generate feature auth
fsd generate entity user
fsd generate widget navbar
fsd generate page dashboard
```

> Architecture shouldn't be something you fix later.  
> It should exist from day one.
